Run the analysis yourself

All displayed analysis results are generated in R from the APSIM wheat dataset. The website serves saved summaries; it does not run a new Gibbs fit when you move a slider.

Small example

The repository includes daily data for 12 actual genotypes at four locations in three years. Run it first to inspect the workflow.

install.packages(c("data.table", "jsonlite"))
# From the repository directory:
# Rscript analysis/run_example.R

R, data.table and jsonlite are free, open-source software. Natural splines and linear algebra use packages bundled with R. ASReml and other proprietary software are not required. Python is used only to assemble the static HTML pages; all numerical analysis is R.

Model limitations

This is a compact approximation of simulated biomass accumulation, not a replacement for APSIM. It has no explicit biomass feedback or positivity constraint. Its Gaussian interval discrepancies need not capture persistent model errors. The optional location and SVD extensions have first-block evaluation only.
