From trajectories to a design matrix

We model changes in biomass over observation intervals. Integrating each feature along the weather sequence produces a design-matrix row, without numerically differentiating the biomass observations.

\[\Delta B_{gej}=\sum_k\underbrace{\int_{t_j}^{t_{j+1}}\phi_k(\mathbf u_e(s))\,ds}_{X_{ejk}}(\beta_k+b_{gk})+\varepsilon_{gej}.\]
\[\mathbf y=\mathbf Z\boldsymbol\theta+\boldsymbol\varepsilon.\]

Each shared feature is accompanied by genotype-specific coefficient blocks. We compute sufficient statistics once, so the sampler does not repeatedly multiply the complete regression matrix.

Observation spacing is 14 days, retaining the final shorter interval. We use trapezoidal quadrature on the daily weather grid and training-only column scaling.
